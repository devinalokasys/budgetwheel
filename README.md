# BudgetWheels

A used-car marketplace web app. React 19 + TypeScript + Vite + Tailwind CSS v4.

## Development

```bash
npm install
npm run dev      # http://localhost:5175
npm run build
npm run lint
```

## Pages

- `/` — Home
- `/browse` — Browse listings
- `/dealer` — Dealer Console (dealer-facing inventory & lead management)
- `/messages` — My Garage / Chat & Leads / Saved
- `/sell`, `/saved`, `/account` — placeholders pending design
